# clearforge-praxis

**Praxis** — action informed by reflection; the loop where theory and practice
feed each other.

This repo is the home for ClearForge's cross-cutting **developer / researcher /
builder / architect / systems-mindset** documents — the "how we think and build"
class of docs that don't belong to any single product repo: methodology, design
philosophy, dev-system designs, principles, and the durable *why* behind how the
fleet is built.

Operating motto: *always learning, always teaching* — understand the why, then
apply it to the next thing.

## What belongs here
Cross-cutting docs about *how* ClearForge builds and reasons. **Not** product code,
and **not** sales/positioning (that lives in `clearforge-playbook`). If a doc is
about methodology, architecture philosophy, research direction, or the builder's
mindset, it belongs here.
